# Support Ticket System

Live Website: http://support-ticket-frontend-s3-kokila.s3-website-us-east-1.amazonaws.com

## Technologies Used
- S3 - Frontend Hosting
- API Gateway - API
- Lambda - Backend
- DynamoDB - Database (Table: support-ticket-system)

## How it Works
User fills form -> API Gateway -> Lambda -> Ticket saved in DynamoDB
